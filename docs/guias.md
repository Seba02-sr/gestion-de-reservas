# Guías de Trabajo y Herramientas

## Convenciones

### Tickets
Formato: `[0010]-[T]-[I1] > Título descriptivo`

### Commits
Formato: `feat(0010): descripción corta` o `fix(0010): corrección breve`

### Ramas
Formato: `0010-t-i1-titulo-descriptivo`

## Flujo de trabajo sugerido
1. Al finalizar la tarea:
   - Registrar tiempo.
   - Crear PR hacia `development` y etiquetar `testing`.
   - Comentar en el ticket con link al PR.
2. En el PR: describir qué y cómo se probó.
3. Revisión y merge: otro dev revisa y confirma pruebas, luego merge a `development`.
4. Mantener esta wiki actualizada cuando haga falta.

## Herramientas necesarias
- IDE: VSCode
- Backend: Java 21, Docker
- Frontend: Node 20+
- Gestión de código: Git + GitHub
- Gestión de proyecto: Quire
